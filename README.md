# Jejak Masa

Permainan digital pembelajaran Sejarah KSSR Tahun 4, 5 dan 6.

- Permainan 1: Ular dan Tangga Sejarah (boleh dimainkan sehingga 4 pemain, termasuk jarak jauh)
- Permainan 2: Dunia Blok Sejarah 3D
- Permainan 3: Wira Sejarah
- Pustaka nota pelbagai visual, soalan boleh dibacakan dan laporan PDF

Buka `index.html` dalam pelayar (folder `nota/` mesti berada di sebelahnya). Tiada pelayan atau akaun diperlukan.

Kod sumber penuh dan fail pembinaan disimpan secara berasingan.
